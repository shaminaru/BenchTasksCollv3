# Task: activity-logger

## Description
Complete the implementation for activity-logger

## Requirements
Build a robust activity logging system that can track user activities and system events.

## Acceptance Criteria
- Logs all user actions with timestamps
- Supports different log levels (INFO, WARNING, ERROR, DEBUG)
- Implements log rotation and archival
- Provides search and filtering capabilities
- Includes a web interface for viewing logs

## Tools Available
You have access to local tools and MCP servers. Use them appropriately.
